# Практическая работа 3_2

3.2 HTTP-запрос и ответ

## Цель и результат работы

Проанализировать HTTP-запрос и ответ для сайта: определить метод, статус, заголовки и тело. Исследован запрос главного HTML-документа Swag Labs. Получен ответ 200 по HTTP/2, тело запроса отсутствует, тело ответа содержит HTML-каркас приложения.

Дата проверки: 29.10.2026 01:47 МСК. Окружение: Windows x64, Chromium 156.0.8078.4, headless, окно 1280 × 900. Объект: https://www.saucedemo.com/.

## Инструмент и порядок получения данных

Сетевые события получены через Chrome DevTools Protocol, домен Network: Network.enable, Network.requestWillBeSent, Network.requestWillBeSentExtraInfo, Network.responseReceived и Network.getResponseBody. Это программный интерфейс DevTools. Для анализа сохранён исходный протокол CDP.

Запуск выполнен в новой сессии браузера без пользовательских cookies. Анализируется основной Document, а не запрос JS, изображения или API. Отслеживание завершено после DOMContentLoaded; тело получено отдельно.

## Тело запроса

В событии запроса отсутствует postData. Для этой навигации GET тело не передавалось; параметры URL также отсутствуют. Нельзя делать вывод об отсутствии тела у всех возможных GET-запросов только на основе одного наблюдения.

| access-control-allow-origin | * | Заявленная политика CORS |

Декодированное тело сохранено в evidence/response.html: 1349 байт. Content-Length относится к сжатому представлению, поэтому может отличаться от размера декодированного HTML.

Фрагменты фактического тела ответа:

<title>Swag Labs</title>

<script type="module" crossorigin src="/assets/index-DnLqFcJI.js"></script>

<div id="root"></div>

HTML содержит корневой контейнер и ссылки на JS-ресурсы. Список товаров и сообщения валидации появляются после выполнения JavaScript; отсутствие их полного текста в исходном HTML не является дефектом.

## Повторение через графическую панель DevTools

1. Открыть сайт и DevTools клавишей F12. 2. Перейти в Network. 3. Очистить список и перезагрузить страницу. 4. Выбрать Document с URL https://www.saucedemo.com/. 5. В Headers проверить Request Method, Status Code, Request Headers и Response Headers. 6. На вкладке Response изучить HTML. Для этого GET раздел Payload не содержит данных формы.

Вывод: запрос успешно получает HTML-документ по HTTPS с HTTP/2. Заголовки описывают тип, сжатие и кэширование; статус 200 характеризует получение ресурса и сам по себе не подтверждает исправность всех функций сайта.
